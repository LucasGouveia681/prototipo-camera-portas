## Sobre o projeto 
no jogo prototipo da camera e perssonagem nós temos que decidir entre 3 portas de que qual é a certa para poder vencer
 
## O que o projeto faz 
- o jogador se movimenta com as setas/WASD
- ao acertar a porta você vence e aparece a mensagem de vitória
- a camera fica em primeira pessoa
 
## O que o projeto contém 
- **Scripts:** PlayerController.cs – movimenta o jogador - interacao -  faz com que seja possivel interagir com as portas - porta -  faz a animação dela
- - gerenciador de portas - faz com que uma das portas seja a correta para vencer
- **Objetos principais:** Player, Ground, Porta 
- **Recursos usados:** Rigidbody, Collider com Is Trigger, TextMeshPro, Camera Controller
 
## Controles 
- WASD/SETAS – Movimenta o personagem
